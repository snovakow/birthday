# Birthday

**TypeScript + React + Vite**

An age tracking app made as a birthday gift. It shows how old Raya is, counted live in years, months, weeks, days, hours, minutes and seconds, and as an exact age in years to eight decimal places.

## Running it locally

You need [Node.js](https://nodejs.org) 22.12 or later. Then, in a clone:

```sh
npm install
npm run dev
```

and open the address it prints.

## Building it

`npm run build` type-checks the app and makes a static site in `dist/` that works from any folder on any web server. `npm run preview` serves that build locally, and `npm run lint` runs Oxlint.
